О программе

              
AmneziaWG GUI — portable-клиент управления сервером по SSH.

            

          

          

            

              

                
              

              

                
AmneziaWG GUI 1.0.0

                
Графическая оболочка для Windows, которая управляет уже установленным сервером AmneziaWG по SSH. Серверная часть — проект bivlked/amneziawg-installer и его скрипт manage_amneziawg.sh.

                
Приложение не устанавливается на сервер, не открывает портов и не хранит приватные ключи в открытом виде.

              

            


            

              
Совместимость

              
Приложение подходит только для серверов, установленных проектом bivlked/amneziawg-installer (Ubuntu / Debian, AmneziaWG 2.0 или 3.1). Оно вызывает команды manage_amneziawg.sh и ожидает его JSON-контракт версии 6.x.

              
    
                
  • Проверено с manage_amneziawg.sh 6.1.1 и AmneziaWG 3.1.
    • 
                
  • Не является форком, официальной частью или заменой amneziawg-installer.
    • 
                
  • Не поддерживает панели других проектов, Docker-развёртывания и ручные конфигурации WireGuard.
    • 
                
  • Автор установщика не поддерживает это приложение и не отвечает за его работу.
